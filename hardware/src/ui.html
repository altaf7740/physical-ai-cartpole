x and ẋ are counted from the steps the Pico commands. The stepper has no position sensor, so pushing the cart by hand doesn't change them, and skipped steps make x drift. After moving the cart by hand, run Home & measure track again.

Manual jog

Speed—

Hold to move, release to stop. Keys: hold ← →, Space/Esc = E-stop. The limit switches stop the cart; it can always move away from a pressed one.

Home (also runs by itself whenever the Pico connects): left switch, then half the measured track, so x = 0 is the centre. Calibrate track measures the track: left switch, right switch, twice, then parks in the middle; run it after changing the rail, pulley or microstepping. Both use the speed above. The travel is the real track length; if a tape measure disagrees, steps_per_meter is wrong. Once homed, Reset counters zeroes θ only.
